# Florida source inventory: Legistar and eSCRIBE (probe of 2026-10-13)

Generated by `scripts/probe_legistar_tokens.py` from the 412 municipalities in
`backend/app/data/fl_municipalities.json` and the 67 counties derived from
them (479 places). Raw results: `docs/data/legistar-probe-2026-10-13.json`.

**Read this first.** The probe *guesses* client tokens, so it finds some
jurisdictions and misses others. A miss means "not found by guessing", not
"not on Legistar". Jacksonville's real token (`jaxcityc`) is not guessable and
was missed. Of the 479 places, 54 answered with a Legistar client;
that is a floor, not a census. For the rest the platform is **unknown**, and
needs a manual sweep (open `<city>.legistar.com`, then the city's own
agendas page).

A hit needs three checks before it counts as coverage: it is the Florida
place (not a same-named city elsewhere), its newest matter is recent, and it
is the jurisdiction's primary system.

## What this means for the Florida-completeness gate

The expansion test ("add a jurisdiction through configuration") is met for
Legistar jurisdictions: one registry entry each (docs/ONBOARDING_A_CITY.md).
The gate itself is far away: about 31 Legistar places are current out of
479 probed, 67 counties and hundreds of municipalities have no known source,
and each non-Legistar platform (OnBase, eSCRIBE, iQM2, others) needs its own
adapter. The next inventory step is a manual platform sweep of the 67
counties and the ~50 largest municipalities.

## Reproducing, and how reliable the data is

Three runs were made on 2026-10-13. Runs 1 and 2 each found 54 Legistar
hits (run 2, which added the Florida check, is the one recorded in
`docs/data/`). Run 3 found none because the machine's DNS resolver started
failing partway through (a long run of failed hostname lookups for the
eSCRIBE check); its results were discarded. A lookup failure is reported as
a miss, so a flaky network under-counts: re-run with `--only` to confirm any
place that matters.

The probe made roughly 10,000 requests to Legistar's public API in total.
Run it rarely, use `--only` for spot checks, and don't loop it.
