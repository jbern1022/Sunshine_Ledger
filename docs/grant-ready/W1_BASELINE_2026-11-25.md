## 3. Proposed demo cases (owner picks)

One state bill, one local ordinance, and a pair that shows the two levels connecting. All three use
records already on the site.

1. **H.B. 1389 (2026 Regular), housing.** Passed; 55 actions, 7 roll calls, 5 amendments, all four layers,
   staff analysis, Census overlay for HD-118. Shows the full state path from filing to law. Caveats to show,
   not hide: the Who-it-affects leftovers (`6hgfjX9c3R5fXX2G`) and the unlabeled Impact Lens baseline.
2. **Jacksonville Ordinance 2026-0851-E, SHIP deadline extension.** Short, readable, full text on file,
   four layers. Pairs with the state housing program (SHIP is funded by the Florida Housing Finance
   Corporation), so a reader sees state money reach a local decision. Its summary defect (D3) makes it a
   good correction-path demonstration once fixed.
3. **S.B. 1166 (2026 Regular), insurer prescription-drug disclosures.** Failed in committee; all four
   layers; the second Impact Lens baseline bill. Shows a bill that did not pass and what the site says
   (and does not say) about effects that will not happen.

Alternative for slot 3 if a federal example is preferred: the NDAA (H.R. 3838) Florida-places findings,
but federal text depends on `CONGRESS_API_KEY`, which is still unset.
